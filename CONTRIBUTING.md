Contributing to AgentOS

Thanks for your interest in contributing! Follow these steps to contribute high-quality changes.

1. Discussion & Issues
   - Open an issue to discuss significant changes before implementing.
   - Include motivation, scope, and any design notes.

2. Development
   - Fork/branch from the appropriate branch.
   - Run ./scripts/bootstrap.sh to prepare your environment.
   - Add tests for new behavior (unit/integration).

3. Commits & PRs
   - Use clear, present-tense commit messages.
   - Include a PR description with rationale and testing steps.
   - Link related issues.

4. Code Quality
   - Keep changes small and focused.
   - Follow existing project patterns and Java 21 conventions.

5. CI
   - Ensure all tests pass on GitHub Actions before requesting review.

For major design changes, open a proposal issue or RFC to gather feedback first.
